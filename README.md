# DeepTimer

A simple python applications that helps developers tracker their daily programming sessions and monitor weekly goals.

## Overview:
DeepTimer is a command-line productivity tool developed
for Hack Club's Terra program.
 
The goal is to help programmers build consistent coding
habits by tracking their development time.

## Features(To be added):

- Start and stop coding sessions
- Track total coding time
- Save session history
- Monitor weekly programming goals

## Tech Stack (TBD):
- Python 3
